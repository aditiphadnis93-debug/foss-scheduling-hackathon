## User personas/roles

The system should support login and usage by different roles and the views should be customized according to it.

### Litigant
- View all the cases that they are part of
- View the details about the case such as filing date, a timeline of the hearings so far
- Each hearing will have a checklist that contains details of the case so far and summary of it. This helps the personas to understand any pending action items.

### Advocates
- View all the cases 
- Calendar view as per causelist-as-a-calendar.md
- Get a summary of each case as it stands.

### Court master
- Full court view: broken down into court rooms
